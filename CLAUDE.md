# tgBotVoiceconvertor

Telegram-бот для себя и пары друзей: голосовое / аудио / видео → транскрипт (OpenAI) → выжимка с кнопками форматов.

## Правила

- **В конце каждой итерации обязательно делать `git commit` и `git push`** в приватный репозиторий. Без исключений.
- Архитектура минималистичная: один файл `bot.py`, состояние в памяти, без БД, очередей и Docker, пока это реально не понадобится.
- Секреты только в `.env` (в `.gitignore`), никогда не коммитить токены.

## Запуск

```
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python bot.py
```

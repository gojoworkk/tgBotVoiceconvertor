# Voice → Summary Telegram Bot

Перешли боту голосовое, кружок, mp3/mp4/m4a/wav/ogg (до 20 МБ) — он расшифрует запись через **Gemini CLI** (по твоей подписке Google, без платного API) и сразу пришлёт короткую выжимку. Под ответом кнопки: **Коротко / Тезисы / Подробно / Задачи / Весь текст**.

## Настройка

1. Поставить Gemini CLI и один раз войти в Google-аккаунт:

```
npm install -g @google/gemini-cli
gemini
```

   В меню выбрать «Sign in with Google», после входа выйти из CLI (`/quit`).

2. `copy .env.example .env` и заполнить `TELEGRAM_BOT_TOKEN` и `ALLOWED_USERS` (свой id можно узнать у @userinfobot).
3. Установить и запустить:

```
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python bot.py
```

## Как устроено

- `bot.py` — всё в одном файле: aiogram 3 (long polling). Файл сохраняется во временную папку, бот вызывает `gemini -p "расшифруй @файл"` в headless-режиме, затем тем же CLI делает выжимки из текста.
- Gemini запускается в режиме `--approval-mode plan` (только чтение), чтобы содержимое записи не могло заставить модель выполнять команды на компьютере.
- Одновременно работают максимум 2 процесса Gemini.
- Транскрипты хранятся в памяти (последние 500). После перезапуска старые кнопки перестают работать — достаточно переслать файл заново.
- Бот работает, пока включён компьютер, на котором выполнен вход в Gemini CLI.
- Ограничение 20 МБ — это лимит Telegram Bot API на скачивание файлов ботом.
